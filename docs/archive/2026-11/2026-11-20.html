标题：Gemini API 推出工具检索：按需加载 schema，减少 token 消耗

来源：Google AI Blog · 2026-11-19

摘要：

  • Gemini Interactions API 预览版新增工具检索功能，可按需加载工具参数 schema，无需每次请求发送完整工具库。
  • 减少输入 token 的同时保持工具选择准确性，直接影响多工具智能体的成本和可靠性。
  • 使用 Gemini API 构建多工具智能体的开发者。

产品技术视角：需实测检索准确率与 token 节省的实际比例，尤其是在工具数量多且高度相似时是否仍能选对工具。

标题：Gemini Mac 版支持操作电脑，可自动执行多步骤任务

来源：The Verge AI · 2026-11-19

摘要：

  • Google Gemini 的 macOS 应用新增 computer use 功能，可跨本地文件、桌面应用和网页完成多步骤任务。
  • 将 AI 代理能力引入桌面操作系统，为自动化办公和复杂工作流提供新的集成方式。
  • Mac 用户和希望将 AI 集成到桌面工作流的团队。

产品技术视角：需验证其在非标准 UI 和复杂授权场景下的可靠性，以及是否需要额外确认步骤来防止误操作。

🔍 今日主题观察

编辑判断：AI 代理正从对话界面转向操作系统级集成，但可靠性验证仍滞后于功能发布。 Gemini 同时开放了 macOS 电脑操作和 API 工具检索；前者让模型直接操作用户系统，后者试图用按需加载减少多工具场景的错误率。两者都指向同一个方向：扩大代理可触达的范围，同时控制复杂度带来的成本。 开发者需要在集成这些能力时建立额外验证层，例如操作历史回放和工具调用审计，不能依赖厂商默认行为保证安全。 在真实任务中对比 Gemini 电脑操作与 API 工具调用的任务成功率和用户干预频率，追踪多步骤任务是否出现错误累积。
