标题：The Verge 记者用 50 美元自制 AI Tamagotchi，揭示 Muse 硬件开放可能

来源：The Verge AI · 2026-10-31

摘要：

  • The Verge 记者使用 50 美元的 Waveshare ESP32 设备，通过 Claude 生成代码和 Muse API 构建了类似 Meta Muse Charm 的 AI 玩具。
  • 表明第三方可以利用 Muse API 和低成本硬件构建实体 AI 设备，为开发者提供了新的硬件交互路径。
  • 希望开发实体 AI 设备的开发者、智能硬件创业者，以及关注 Meta Muse 生态的厂商。

产品技术视角：该自制设备缺少摄像头和蜂窝网络，且需要大量额外代码才能实现智能家居控制，说明 API 开放程度和功能完整性仍需验证。

📰 其他值得看的

  • TechCrunch 报道自动驾驶行业迎来新一波热潮 · TechCrunch

    Trucks VC 称 2026 年已收到 81 家新自动驾驶初创公司的融资申请，超过历史纪录，认为这是由 AI 突破驱动的第二波热潮。

  • NVIDIA TensorRT Edge-LLM 简化边缘 AI 开发 · NVIDIA Technical Blog

    NVIDIA 推出 TensorRT Edge-LLM，提供轻量 C++ 推理运行时和 trtedge CLI，可在 DGX Spark 上开发并部署到 Jetson Thor、DRIVE AGX Thor 和 IGX Thor。
