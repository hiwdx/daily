标题：Sam Altman 呼吁减缓 AI 发展速度

来源：TechCrunch AI · 2026-08-02

摘要：

  • Sam Altman 在公开讨论中呼吁行业“控制 AI 发展速度”。
  • OpenAI 的 CEO 首次公开站到减速一方，可能直接影响产品发布节奏、开发者对路线图的预期以及监管讨论。
  • 依赖 OpenAI API 的开发者、关注 AI 安全的公众以及处于监管讨论中的其他模型厂商。

产品技术视角：该声明可能很快表现为 API 发布放缓或更严格的使用政策，改变接入方的产品迭代计划。

标题：支付版税能说服艺术家拥抱 AI 吗？

来源：The Verge AI · 2026-08-02

摘要：

  • 插画师持续抗议未经许可训练 AI，生成式 AI 公司开始讨论向艺术家支付版税的模式。
  • 版税模式若落地将改变数据供应链，影响模型训练成本，并推高图像生成类产品的定价。
  • 创意工作者、依赖图像生成 API 的开发者和企业用户。

产品技术视角：Midjourney、Stable Diffusion 等产品可能被迫公开训练数据来源并支付费用，改变成本结构和产品策略。
