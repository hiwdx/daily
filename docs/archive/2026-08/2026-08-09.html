标题：GitHub Copilot 周更：恢复工作上下文、代码审查分级等多项能力上线

来源：GitHub Changelog · 2026-08-07

摘要：

  • GitHub Copilot 在桌面、CLI 和 VS Code 中推出多项更新，支持恢复工作上下文、按风险分级审查代码等功能。
  • 开发者无需重复解释项目背景即可接续工作，审查深度可匹配代码复杂度，直接减少打断和无效审查，提升编码流。
  • 使用 GitHub Copilot 的开发者与团队，尤其频繁切换任务或代码审查者。

产品技术视角：将 AI 辅助从单次问答升级为上下文保持和可控审查，强化了 Copilot 作为工作流核心的定位。

标题：Vercel AI Gateway 与 Sandbox 接入 NousResearch 编程智能体 Hermes

来源：Vercel Changelog · 2026-08-07

摘要：

  • NousResearch 编码智能体 Hermes 现通过 Vercel AI Gateway 路由请求，并在 Vercel Sandbox 云微虚拟机中执行命令。
  • 智能体的模型调用和命令执行均获得托管式基础设施支持，降低了构建可行动的 AI 工具的门槛和运行风险。
  • NousResearch 用户、需在云端安全运行智能体的开发者。

产品技术视角：Vercel 平台能力向第三方智能体开放，从静态部署延伸至动态 agent 运行，拓展了平台型中间件的边界。

标题：Rippling 发布 AI Spend Console，量化员工 AI 开支与产出

来源：TechCrunch AI · 2026-08-07

摘要：

  • HR 与 IT 平台 Rippling 推出 AI Spend Console，可追踪个人和团队 AI 工具花费并关联产出。
  • 企业 AI 开支正从零散报销转为可量化、可优化项，直接影响采购决策和工具合规。
  • 采用多 AI 工具的企业 IT 和财务团队，以及相关工具供应商。

产品技术视角：将 AI 消费管理产品化，抓住企业隐性开支失控的痛点，把成本可见性化为可卖功能。
