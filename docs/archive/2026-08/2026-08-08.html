标题：Cloudflare 推出统一模型访问和计费，AI Gateway 与 Workers AI 打通

来源：Cloudflare Changelog · 2026-08-07

摘要：

  • Workers AI 和 AI Gateway 现在统一了模型访问和计费，开发者可用同一套 API 调用 Cloudflare 托管的模型和第三方模型，并获得统一的观测、缓存、安全和计费控制。
  • 这直接简化了多模型接入和推理流量的管理，开发者不再需要为不同供应商维护多套对接逻辑，降低工程开销并改善成本可见性。
  • 在 Cloudflare 上构建 AI 应用的开发者，以及希望统一管理和监控推理调用成本与性能的团队。

产品技术视角：通过一个 AI binding 和 REST API 即可访问 Workers AI 与第三方模型，AI Gateway 提供统一的观测、缓存和安全层，显著降低多模型运维复杂度。

标题：Vercel AI Gateway 上线字节跳动 Seedance 2.5，支持 30 秒视频生成

来源：Vercel Changelog · 2026-08-06

摘要：

  • 字节跳动的视频生成模型 Seedance 2.5 现在在 Vercel AI Gateway 上可用，单次可生成最长 30 秒视频，支持多模态参考、定向编辑和异步生成。
  • 将先进的视频生成模型通过 serverless 网关分发，让前端和全栈开发者能直接在应用中加入 30 秒视频生成能力，无需管理 GPU 基础设施。
  • 在 Vercel 上构建交互式视频应用的开发者，以及希望快速集成视频生成功能的产品团队。

产品技术视角：Seedance 2.5 的多模态参考和定向编辑能力，加上 Vercel 边缘平台的异步生成支持，意味着开发者可以构建更复杂的视频创作工作流，并让生成任务突破 serverless 超时限制。

标题：Copilot 用量指标 API 新增 Agent App 活动追踪

来源：GitHub Changelog · 2026-08-07

摘要：

  • GitHub Copilot 的用量指标 API 现在可以返回 Agent App（如 Claude 和 Codex）的活动数据，组织可以量化这些应用在开发工作流中的使用情况。
  • 团队能够根据实际数据评估不同 AI 代理对开发效率的影响，从而优化工具选择和资源分配，推动代理在开发流程中的落地。
  • 使用 GitHub Copilot 的企业和团队管理者，尤其是那些已在工作流中集成第三方 AI 代理的开发者。

产品技术视角：通过 API 提供 Agent App 的活动追踪，Copilot 让企业可以像监控开发者工具一样量化 AI 代理的参与度，这为采购和使用决策提供了数据支撑。
