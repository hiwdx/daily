标题：GitHub 停用 Copilot Billing Preview 应用，将计费管理直接整合到设置中

来源：GitHub Changelog · 2026-08-04

摘要：

  • GitHub 正式退役 Copilot Billing Preview 独立应用，相关花费查看与管理功能已集成至 GitHub 账单设置。
  • 开发者不再需要单独安装应用来监控 Copilot 开支，管理路径更短、更统一，降低了结算摩擦。
  • 所有使用 GitHub Copilot 并需要追踪花费的团队和组织。

产品技术视角：计费功能从边缘应用收回到平台设置，意味着 Copilot 正从附加工具变成 GitHub 核心付费能力的一部分。

标题：Cloudflare Agents SDK 上线 Agent 调用链追踪，覆盖 Think、Flue 和 AI SDK

来源：Cloudflare Changelog · 2026-08-04

摘要：

  • Cloudflare 为基于 Agents SDK 构建的应用提供 agent 调用链追踪，可在一次 agent 轮次中看到模型调用、工具执行、审批、token 用量及 Workers 运行时操作。
  • agent 应用调试长期缺乏端到端可见性，此次内置追踪让开发者能直接定位性能瓶颈和异常步骤。
  • 在 Cloudflare Workers 上构建 AI agent 的开发者。

产品技术视角：将可观测性深度嵌入 agent 运行时，降低了从开发到生产的操作门槛，并强化了 Cloudflare 的 agent 基础设施定位。

标题：Vercel 为 eve agent 接入浏览器，agent 可像人类一样操控网页

来源：Vercel Changelog · 2026-08-04

摘要：

  • Vercel 推出 @agent-browser/eve 扩展，让 eve agent 获得完整的浏览器工具集，可导航、阅读内容、点击、填写表单等。
  • agent 直接操控浏览器是自动完成复杂在线任务的关键一步，此次集成使网页交互能力成为 eve agent 的原生功能。
  • 使用 Vercel eve 构建 agent 的开发者，以及需要 web 自动化能力的产品团队。

产品技术视角：通过一个扩展即获得浏览器操作能力，大幅降低了构建可上网 agent 的开发成本，并可能加速电商、表单填写等场景的落地。
