标题：OpenAI 推出法律专用平台 Astra for Law

来源：OpenAI · 2026-09-17

摘要：

  • OpenAI 发布 Astra for Law，提供定制工作流、法律数据源连接和机密客户工作的法律级控制。
  • 前沿模型能力与法律级合规控制首次结合，直接切入高价值专业服务市场。
  • 律师事务所、企业法务及依赖法律文件的客户。

产品技术视角：通过连接法律数据源和定制工作流，提供符合行业标准的专用工具。

标题：Google 与联合国推出 UN System Data Commons 开放数据平台

来源：Google AI Blog · 2026-09-17

摘要：

  • Google 与联合国系统合作推出 UN System Data Commons，让全球统计数据更易访问和搜索。
  • 将权威全球数据与 AI 搜索结合，降低数据获取门槛，可能改变公共政策分析方式。
  • 研究人员、政策制定者和需要全球数据的普通用户。

产品技术视角：提供开放平台，利用 AI 增强数据探索和可访问性。

标题：Anthropic 升级 Claude Code Projects：云中管理多个 AI 代理

来源：The Verge AI · 2026-09-17

摘要：

  • Claude Code 重新推出 Projects 功能，允许用户在云端运行多个 AI 代理，共享记忆、目标和文件库。
  • 开发者可并行处理多个任务并由协调器统一管理，缩短复杂工作流构建时间。
  • 使用 Claude Code 的软件开发者和小型工程团队。

产品技术视角：通过共享上下文和并行线程，简化多代理协作的开发流程。
