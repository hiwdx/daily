标题：Cloudflare MCP 服务器门户正式可用

来源：Cloudflare Changelog · 2026-09-24

摘要：

  • Cloudflare 将 MCP 服务器门户转为正式版，提供统一端点、网关路由和代码模式策略。
  • 企业现在可以安全地标准化接入多个 MCP 服务器，简化 AI 代理调用外部工具的权限管理与审计。
  • 使用 Cloudflare One 的企业开发者和安全团队。

产品技术视角：MCP 服务器门户成为 Cloudflare 边缘网络的一部分，增强了 AI 代理与企业工具集成的安全性和可观测性。
